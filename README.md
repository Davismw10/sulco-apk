# Sulco — APK

Descarrega a versão mais recente do Sulco (Android) em **[Releases](../../releases/latest)**.

## Instalar
1. Abre a página de Releases e descarrega o ficheiro `.apk`.
2. No Android, permite a instalação de apps de origem desconhecida quando for pedido.
3. Abre o ficheiro descarregado e instala.

Nota: é uma build de teste (debug).
